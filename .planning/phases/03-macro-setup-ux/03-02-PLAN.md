## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User keydown → document listener | Keyboard events from OS intercepted in WebView capture phase |
| Frontend → IPC (card edit) | invoke("bind_hotkey") / invoke("set_macro_trigger_key") originate from user interaction |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | Key capture listener | mitigate | e.preventDefault() + e.stopPropagation() in capture phase prevents captured key from acting on UI; listener removed immediately after capture to prevent state leaks |
| T-03-07 | Tampering | Card edit bind_hotkey | mitigate | Calls unbind_hotkey before bind_hotkey per Pitfall 3 in RESEARCH.md — prevents duplicate hotkey bindings on the same macro |
| T-03-08 | Denial of Service | Multiple listener attach | mitigate | Module-level _keyCaptureListener ref enforces single-listener invariant; prior listener always removed before new attach |
| T-03-09 | Spoofing | navigator.platform detection | accept | Used only to select display name lookup table; wrong selection results in incorrect display name but no security boundary crossed; same-process Tauri trust model |
</threat_model>
