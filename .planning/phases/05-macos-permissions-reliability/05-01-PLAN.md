<objective>
Arm the CGEventTap on any post-launch accessibility grant path (RELY-06) and eliminate the block v0.1.6 deprecation warning (BUILD-02).

Purpose: The current `check_accessibility` IPC handler only calls `AXIsProcessTrusted()` and returns — it never arms the tap. A user who grants permission via System Settings must restart the app for macros to work. This plan fixes that by mirroring the existing `request_accessibility` pattern (which already calls `initialize_tap()`) into `check_accessibility`. Additionally, `cocoa = "0.26.1"` is the sole source of the `block v0.1.6` deprecation warning; removing the unused direct dependency eliminates the warning at the source.

Output: Modified `ipc/mod.rs` with tap-arming in `check_accessibility`, and a `Cargo.toml` without the `cocoa` entry. Both changes are Rust-layer only — no frontend or schema changes.
</objective>
