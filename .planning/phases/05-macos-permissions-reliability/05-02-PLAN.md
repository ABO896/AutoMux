<objective>
Add a "Pending approval…" UI state between clicking Grant Access and the OS dialog resolving (PERM-01, D-01, D-02).

Purpose: Currently, clicking Grant Access triggers `request_accessibility` which returns `false` before the user has acted on the OS dialog. The UI immediately shows "Denied" again — the false "not granted" state that PERM-01 must fix. This plan adds one SolidJS signal (`accessibilityPending`), a module-level timeout handle (`_pendingTimeoutId`), a `clearPending()` helper, updates `handleRequestAccess` to enter the pending state, updates the 3s polling effect to clear pending on grant, and restructures the accessibility status Show block to a 3-branch rendering.

Output: Modified `App.tsx` with the pending state machine fully wired. No Rust changes, no new files.
</objective>
