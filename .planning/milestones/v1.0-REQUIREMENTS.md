## v1 Requirements (All Complete)

### Reliability

- [x] **RELY-01**: macOS permissions check correctly starts the event tap when accessibility permission transitions from denied to granted — no false "security denied" prompt after grant
  - **Outcome:** Validated via 3s frontend poll. *Partial:* passive System Settings grant without clicking "Request Access" still requires app restart (documented in audit as integration gap).
- [x] **RELY-02**: macOS CGEventTap re-enables itself when the OS disables it via timeout (kCGEventTapDisabledByTimeout) — hotkeys do not silently stop working during long sessions
  - **Outcome:** Validated — TapDisabledByTimeout detection + CGEventTapEnable inline re-enable.
- [x] **RELY-03**: Windows emergency stop (Ctrl+Shift+Q) flushes held inputs before exiting — no keys left stuck after macro stop
  - **Outcome:** Validated — synchronous flush_held_inputs() before process::exit.
- [x] **RELY-04**: Macro changes are auto-saved after every mutation — no user work lost on app restart
  - **Outcome:** Validated — Arc<ProfileManager> injected into StateActor; loading_profile guard prevents storm on startup.

### Safety

- [x] **SAFE-01**: All 5 production `unwrap()` / `expect()` calls on the input injection hot path replaced with recoverable error handling — app cannot panic during macro execution
  - **Outcome:** Validated — all 5 sites replaced with let-Ok/let-Some guards.
- [x] **SAFE-02**: MacPlatformObserver resource leak fixed — observer token is correctly reclaimed; `stop_observing` is no longer dead code
  - **Outcome:** Validated — observer stored via app.manage() for application lifetime.
- [x] **SAFE-03**: Minimum macro interval floor enforced at 5ms — intervals below this threshold are rejected or clamped to prevent system instability
  - **Outcome:** Validated — scheduler-layer clamp at both IntervalTask::new and UpdateInterval handler.

### README & License

- [x] **README-01**: README prose corrected from "MIT License" to "GNU GPL v3" — no legal contradiction between prose and actual license file
  - **Outcome:** Validated — GPL-3.0 prose + explicit LICENSE file at repo root.
- [x] **README-02**: Correct GPL-3.0 badge added to README (shields.io SPDX identifier `GPL-3.0-only`)
  - **Outcome:** Validated — shields.io badge with `GPL-3.0-only` SPDX identifier.
- [x] **README-03**: README copy improved for appeal and clarity to new users — accurately represents features, platforms, and purpose
  - **Outcome:** Validated — opening paragraph rewritten to lead with user value.

### Codebase Cleanup

- [x] **AUDIT-01**: `implementation_plan.md` and other non-project planning documents removed from repository root
  - **Outcome:** Validated — deleted via git rm.
- [x] **AUDIT-02**: Dead/unused source files identified and removed across Rust and SolidJS layers
  - **Outcome:** Validated — RUSTFLAGS="-Wdead-code" cargo check passed clean.
- [x] **AUDIT-03**: Debug artifacts and temp files removed and added to `.gitignore`
  - **Outcome:** Validated — Thumbs.db, *.log entries added; src-tauri/gen/ covered.

### UX — Macro Setup

- [x] **UX-01**: Key Code field replaced with a key capture widget — user presses the key and it is captured; raw CGKeyCode/VK integers never shown to user
  - **Outcome:** Validated — keymap.ts resolveKeyName + key capture widget in creation form and card inline edit.
- [x] **UX-02**: macOS target app field replaced with a running-process picker showing app name + bundle ID — no manual text entry required
  - **Outcome:** Validated — list_running_apps IPC backed by NSWorkspace; process picker <select> in UI.
- [x] **UX-03**: Windows target app field replaced with a running-process picker showing process name and path — no manual text entry required
  - **Outcome:** Validated — Windows process enumeration via EnumProcesses; same picker UI.

### CI & Distribution

- [x] **CI-01**: macOS release CI verified to produce universal binary (arm64 + x86_64) — not arm64-only
  - **Outcome:** Mechanically enforced — `--target universal-apple-darwin` + blocking lipo verification step. Live confirmation pending next release tag push.
- [x] **CI-02**: GitHub Actions SHA pinning added to release.yml for security hardening
  - **Outcome:** Validated — dtolnay/rust-toolchain and tauri-apps/tauri-action pinned to full 40-char SHAs with tag annotations.
