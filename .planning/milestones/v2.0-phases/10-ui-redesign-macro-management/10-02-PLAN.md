<objective>
Establish the design-token and theme foundation the whole redesign depends on: restructure `App.css` from a single flat `@theme` block into a dark `:root` + `[data-theme="light"]` override + `@theme inline` mapping (Tailwind v4's documented attribute-driven theming), consolidate typography to the UI-SPEC's 4 sizes / 2 weights, finalize the translucent `.glass-card` and add `.sidebar-glass`, and wire the runtime theme system (`theme.ts` + boot script + live `matchMedia` follow).

Purpose: this is the single mechanism for BOTH the light/dark tokens (D-06/D-07) and the `color-mix` translucency the glass surfaces read through (D-03). Everything visual in plans 10-03/10-04/10-05 renders against these tokens, so they must be correct and measured for perf (UI-04) before more surfaces are built on top.

Output: a working System/Light/Dark token set applied before first paint, plus finalized glass/sidebar CSS classes. This finalizes the interim `.glass-card` from plan 10-01.
</objective>
