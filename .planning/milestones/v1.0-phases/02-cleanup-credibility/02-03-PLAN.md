| Boundary | Description |
|----------|-------------|
| Tauri setup closure → app event loop | Resources created in setup must either be stored or intentionally dropped. Silent drop of an OS-event-tap observer leaves dangling native resources. |
| Rust ownership → CGEventTap native lifecycle | The observer holds a raw pointer (`Option<usize>` token) to a macOS CFRunLoop source; premature drop without invoking `stop_observing` leaks the native callback registration. |
